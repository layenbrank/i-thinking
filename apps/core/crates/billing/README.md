# billing · 订阅与计费

订阅、配额与账单：套餐状态机、额度扣减与支付订单。

## 数据所有权

| 表 | 说明 |
| --- | --- |
| `subscription` | 租户订阅（套餐、周期、配额）。 |
| `payment_order` | 支付订单与账单状态。 |

## 对外接口

- 订阅查询与状态变更、配额校验与扣减的原子入口。
- 订单状态机：创建、支付回调推进、退款与对账。
- 支付渠道端口（通道适配由调用方注入，如微信 / 支付宝）：本 crate 定义契约，不直接出站。

## 边界约束

- 不依赖 HTTP 框架；不依赖 `service`（R1）。
- 金额一律使用最小货币单位的整数，禁止浮点。
- 不 JOIN 其他 crate 的表：需要身份或用量信息时，通过调用方传入的参数或 `audit` 事件获得。
- 权限判断调用 `authz`（R3）。
