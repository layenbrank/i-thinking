# 业务错误码说明

本服务所有 API 的 HTTP 状态码均为 **200**，业务结果通过响应 body 中的 `code` 字段判断。

## 编码规则（XXYYZZ）

| 段位 | 含义 |
|------|------|
| XX | 模块代码 |
| YY | 功能代码 |
| ZZ | 错误序号 |

## 常用状态码

| code | 含义 |
|------|------|
| 200000 | 成功 |
| 200001 | 缺少参数 |
| 200002 | 参数格式错误 |
| 200003 | 参数值无效 |
| 300001 | 用户未登录 |
| 300002 | 凭证无效 |
| 300003 | Token 过期 |
| 300006 | 权限不足 |
| 400001 | 资源不存在 |
| 500101 | 用户不存在 |
| 500102 | 用户名已存在 |
| 500201 | 不支持的文件类型 |
| 500204 | 文件不存在 |
| 500301 | 登录凭证无效 |
| 600001 | 数据库错误 |
| 700001 | 数据不一致 |

完整定义见 [`src/utils/response.rs`](../src/utils/response.rs)。

## Apifox 断言建议

断言 `body.code === 200000` 而非 HTTP status code。

## 开发环境字段

`ApiErrorResponse.details` 仅在开发环境返回，生产环境不包含此字段。
